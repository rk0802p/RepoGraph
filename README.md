# RepoGraph

**Semantic Code Dependency & Change-Impact Explorer**

RepoGraph is a developer tool designed to help engineers understand unfamiliar codebases, explore code dependencies, search implementations by intent, and assess the potential impact of code changes.

## Initial Objectives

- Import and inspect a software repository.
- Extract files, functions, classes, and imports.
- Build a source-backed dependency graph.
- Enable code search and dependency exploration.
- Provide evidence-grounded repository Q&A.
- Analyze Git diffs and identify potentially affected code and tests.

## Development Approach

RepoGraph will be developed incrementally, beginning with the application foundation and repository ingestion. Each milestone will be tested before introducing the next layer of functionality.

## Initial Technology Stack

- React, TypeScript, Vite, and Tailwind CSS
- Node.js and Express
- Tree-sitter for code parsing
- PostgreSQL for structured storage
- Python for analysis and AI workflows
